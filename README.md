# 🎮 Jogo da Adivinhação (Número Secreto)

Um jogo web simples e divertido onde o jogador precisa descobrir o número secreto gerado aleatoriamente pelo sistema. O projeto foi desenvolvido com **HTML, CSS e JavaScript puro**, sem dependências externas, e é ideal para praticar lógica de programação e manipulação do DOM.

---

## 📋 Sobre o projeto

O **Jogo da Adivinhação** sorteia um número secreto e dá dicas ao jogador a cada tentativa, informando se o número secreto é **maior** ou **menor** que o chute realizado. O objetivo é acertar o número no menor número de tentativas possível.

O projeto possui uma interface estilizada, com fundo em gradiente, imagens de apoio e layout responsivo para diferentes tamanhos de tela.

---

## ✨ Funcionalidades

- **Geração de número aleatório** — O sistema sorteia um número secreto no início de cada partida.
- **Dicas a cada tentativa** — O jogo informa se o número secreto é maior ou menor que o chute.
- **Contador de tentativas** — Ao acertar, o jogador recebe uma mensagem com a quantidade de tentativas utilizadas.
- **Botão "Novo Jogo"** — Permite reiniciar a partida a qualquer momento.
- **Layout responsivo** — A interface se adapta a telas menores.
- **Código simples e didático** — Ideal para estudos de JavaScript e manipulação do DOM.

---

## 🛠️ Tecnologias utilizadas

- **HTML5** — Estrutura da página.
- **CSS3** — Estilização, gradientes, responsividade e animações.
- **JavaScript (ES6+)** — Lógica do jogo, sorteio, verificação e manipulação do DOM.

O projeto não utiliza frameworks ou bibliotecas externas, sendo executado diretamente no navegador.
